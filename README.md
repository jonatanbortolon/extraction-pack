# Extraction Resource Pack

Resource pack for the **Extraction** Minecraft server (Paper 26.1.2).

The server sends this pack automatically when you join, so you don't need to install it yourself.

## Download

Get `ExtractionResourcePack.zip` from the [latest release](../../releases/latest).

## Manual install

1. Download `ExtractionResourcePack.zip`.
2. Move it to your `.minecraft/resourcepacks` folder. Don't unzip it.
3. In Minecraft, open **Options → Resource Packs** and enable **Extraction**.

## Versions

Each release has its own tag (`v1`, `v2`, ...). The server always points to one specific release, so older links keep working.
